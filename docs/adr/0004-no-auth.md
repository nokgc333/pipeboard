# ADR-0004: 認証・権限管理をv1スコープ外とする設計判断

## Status
Accepted (2026-09-07)

## Context
PipeBoard miniは個人開発ポートフォリオであり、単一利用者・デモ用途を想定している。

## Decision
v1では認証・認可機構を一切実装しない。全APIエンドポイントは認証不要とし、README上で
「Not in scope (v1)」として明記する。

## Consequences
良い: 実装・テストの範囲を機能の核（カンバン・バージョン管理・コメント）に集中でき、
      3週間という制作期間内で実現可能な規模に収まる
悪い: 本番運用する場合はOAuth2/JWT等の導入が必須。同時編集の競合制御（楽観ロック）も
      認証（ユーザー識別）を前提とするため、これも将来拡張として残る

## Alternatives Considered
- 簡易Basic認証の追加: 実装コストは低いが、認証を追加すること自体がスコープクリープの
  第一歩になりやすいと判断し、v1では見送った（パイプライン転職ロードマップのリスク管理を参照）
